# TCW-008 implementation ledger

## Scope

This packet adds the narrow browser-generated texture mirror to the existing native Dawn cube. The browser remains authoritative; the native side validates and applies the current 256x256 RGBA8 texture on the render-owner thread, then returns native reference-upscaled pixels. DLSS, Streamline, overlays, extensions, installers, and arbitrary Three.js compatibility remain out of scope.

## Decisions

- TextureUpload is message type 51 with resource id 1, monotonically increasing revision, 256x256 RGBA8 bytes, and a single pending upload quota.
- TextureAccepted is message type 52. NativeImage carries the applied texture revision so the browser rejects stale returns.
- The browser uses one deterministic byte generator for its Three DataTexture and the bridge upload. Native Dawn uses a nearest sampler, no mipmaps, and a WGSL sampled texture.
- IXWebSocket remains an untouched submodule. The top-level build-tree copy normalizes CRLF to LF, verifies the pinned source hash and requires each transport patch anchor exactly once. The generated patched source identity is emitted at configure time.

## Review boundary

Phase 1 transport checks and TCW-008 evidence are recorded under `artifacts/tcw-008/`. This work stops after push for supervisor review. The final demo is not left running.
