# TCW-007 implementation plan

1. Preserve the accepted TCW-004 and TCW-006R boundaries and add only the
   native reference-upscale return path required for browser presentation.
2. Read back the completed D3D12 output after the GPU fence, mark it with a
   native-only magenta diagnostic, and send bounded authenticated RGBA8 image
   messages at a 12 FPS target.
3. Validate image metadata and session/resize identity in TypeScript, display
   returned pixels in a browser overlay, and fall back without resetting the
   browser-authoritative simulation.
4. Add focused protocol coverage and record browser/native return evidence.

This is a CPU readback/copy diagnostic transport, not zero-copy and not a final
presentation path. DLSS, Streamline, extensions, installers and a custom
Three.js backend remain out of scope. Unresolved TCW-006R temporal findings are
tracked debt and are not revalidated exhaustively by this packet.
