Local absolute paths are deliberately represented by variables. $CHECKOUT is the
detached clean checkout, $DAWN_ROOT the recovered pinned cache, $PYTHON the local
Python executable, $GO_BIN its Go companion, $CHROME the installed Chrome for
Testing executable, and $RAW the ignored output directory outside $CHECKOUT.
Public build output replaces those paths with the same variables. Raw output
hashes and public output hashes are recorded in output-integrity.json.
